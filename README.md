# Mid Penn Trailblazers

A responsive, single-page static website for the Mid Penn Trailblazers trail running club. Built with plain HTML, CSS, and a small amount of JavaScript—no build step or dependencies required.

## Preview locally

Open `index.html` in a browser, or use the VS Code Live Server extension for a local preview.

## Project files

- `index.html` — page structure and club content
- `styles.css` — responsive layout, colors, and typography
- `script.js` — accessible mobile navigation and current copyright year

The race dates, fun-run schedule, results, and community links were adapted from the legacy club website. Schedules may change; the site directs visitors to the club’s Facebook page to confirm current details. Hero photography and fonts are loaded from Unsplash and Google Fonts.
